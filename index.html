💞 Nossa Tela

Compartilhe sua tela direto no navegador, de você para ela. Sem cadastro, sem servidor.

Como funciona: quem compartilha gera um código e manda por WhatsApp. Quem assiste cola, gera um código de resposta e devolve. Cola de volta e pronto: a conexão é direta entre vocês dois.

1. Escolha o que compartilhar

Dica: para o som sair, escolha Tela inteira (ou uma aba) e marque "Compartilhar áudio do sistema" na janelinha do navegador. Se compartilhar só uma janela, o som não é enviado.

2. Envie este código para ela

Copie e mande por WhatsApp.

3. Cole aqui o código de resposta dela

1. Cole o código que você recebeu

2. Devolva este código

Copie e mande de volta. Assim que ele conectar, a tela aparece abaixo.
